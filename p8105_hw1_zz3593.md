## Problem 1

The `penguins` dataset contains measurements of Adelie, Chinstrap, and
Gentoo penguins from the Palmer Archipelago. Important variables include
`species` (Adelie, Chinstrap, or Gentoo), `island` (Biscoe, Dream, or
Torgersen), `bill_length_mm`, `bill_depth_mm`, `flipper_length_mm`, and
`body_mass_g`. The `sex` variable records female or male.

I used `pull()` to extract each variable from the data frame before
calculating its mean. The numeric variable has a numeric mean. R also
calculates a mean for the logical variable by treating `TRUE` as 1 and
`FALSE` as 0; this mean is the proportion of values that are `TRUE`. The
character and factor variables do not have meaningful arithmetic means,
so their calls to `mean()` return `NA` with a warning.

``` r
mean(pull(homework_data, normal_sample))
```

    ## [1] 0.07462564

``` r
mean(pull(homework_data, is_positive))
```

    ## [1] 0.5

``` r
mean(pull(homework_data, character_variable))
```

    ## Warning in mean.default(pull(homework_data, character_variable)): argument is
    ## not numeric or logical: returning NA

    ## [1] NA

``` r
mean(pull(homework_data, factor_variable))
```

    ## Warning in mean.default(pull(homework_data, factor_variable)): argument is not
    ## numeric or logical: returning NA

    ## [1] NA

Converting a logical vector to numeric maps `FALSE` to 0 and `TRUE`
to 1. Converting these character values produces `NA` because they are
not numeric strings. Converting a factor to numeric returns its internal
level codes rather than the labels. This helps explain why the logical
mean can be interpreted as a proportion, while character and factor
means are not meaningful.

``` r
as.numeric(pull(homework_data, is_positive))
as.numeric(pull(homework_data, character_variable))
as.numeric(pull(homework_data, factor_variable))
```
